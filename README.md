# Competitor Matrix for E.ON in the Czech retail market

This file stores a structured view of the main retail competitors that matter for E.ON in the Czech Republic.

## Included competitors

- ČEZ Group
- Pražská energetika (PRE)
- Pražská plynárenská
- MND a.s.
- Centropol Energy

## Core dimensions tracked

- Market share and geographic footprint
- Tarif competitiveness and pricing transparency
- Customer segments served
- Brand trust and service quality
- Digital experience and self-service capability
- Green energy and renewable offering
- Regulatory compliance and strategic adaptation
- Infrastructure and vertical integration
- Strategic partnerships and M&A activity
- Hiring / public signals

## Data file

- `competitor_matrix.json`

This is a lightweight static structure meant for manual monitoring and future expansion into automated scraping.
