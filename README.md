# Competitor scorecard

`competitor_scorecard.json` contains a preliminary relative scorecard for ČEZ Group, PRE, Pražská plynárenská, MND and Centropol, benchmarked against E.ON in Czech retail electricity and gas.

## Important interpretation

These are **directional hypotheses**, not a verified ranking. Most scores have low confidence because a comparable evidence set has not yet been collected. `NA` means there is not enough evidence to score; it does not mean poor performance. No total score is calculated.

### Scale

- **1** — limited relative position
- **2** — below average / limited evidence of strength
- **3** — competitive / broadly comparable
- **4** — strong relative position
- **5** — leading relative position
- **NA** — not enough reliable evidence

## Dimensions

The scorecard covers market footprint, tariff competitiveness and transparency, customer segments, brand and service, digital experience, green offers, regulatory adaptation, vertical integration, partnerships/M&A, and public news/hiring signals. Each dimension includes suggested evidence sources in the JSON file.

## How to make it decision-ready

1. Collect dated, primary-source evidence for every supplier.
2. Compare the same tariff profiles, contract terms, customer segments and time period.
3. Replace low-confidence scores with evidence-backed ratings and add source URLs and observation dates.
4. Agree on dimension weights with stakeholders before calculating any overall score.
