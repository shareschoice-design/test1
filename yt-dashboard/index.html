Nastavení – Google OAuth Client ID

Dashboard běží celý v tvém prohlížeči. Data jdou jen mezi prohlížečem a Google API, nikam jinam. Potřebuješ jednou vytvořit vlastní OAuth Client ID:

  1. Otevři Google Cloud Console → vytvoř projekt (např. „YT dashboard“).
  2. APIs & Services → Library: zapni YouTube Data API v3 a YouTube Analytics API.
  3. OAuth consent screen: typ External, stav Testing. Do Test users přidej všechny Google účty, pod kterými máš kanály.
  4. Credentials → Create credentials → OAuth client ID → typ Web application. Do Authorized JavaScript origins přidej adresu, odkud stránku otevíráš (např. ).
  5. Zkopíruj Client ID (končí na .apps.googleusercontent.com) a vlož ho sem:
Správa dat

Seznam kanálů a historie čísel (pro výpočet změn za 48 h) se ukládá jen v tomto prohlížeči. Přístupové tokeny platí cca 1 hodinu a drží se jen v této záložce.

Všechny kanály

Jak se počítá „48 h“: nová videa a komentáře jsou přesně za posledních 48 hodin. Změna odběratelů a zhlédnutí se počítá z uložených snímků v tomto prohlížeči – otevírej dashboard aspoň jednou denně, ať je s čím srovnávat. YouTube Analytics (graf) má zpoždění 1–3 dny. Koncepty, které nikdy nebyly dokončeny, API nevrací – „neveřejná“ = soukromá + neveřejná (unlisted) + naplánovaná.
