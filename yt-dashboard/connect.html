Připojení YouTube kanálů

Jednorázové nastavení. Pak se data stahují sama každou hodinu a dashboard je jen otevřeš.

1 Google klíč (jednou, cca 5 minut)

  1. Otevři Google Cloud → nový projekt, pojmenuj ho např. YT dashboard → Create.
  2. Zapni obě API (tlačítko Enable): YouTube Data API v3 a YouTube Analytics API.
  3. OAuth consent screen → Get started → název aplikace libovolný, svůj e-mail, typ External → Create.
  4. V části Audience klikni na Publish app (stav „In production“). Jinak Google přístup po 7 dnech zruší a automatika by přestala fungovat.
  5. Create OAuth client → typ Web application:
    Authorized JavaScript origins:
    Authorized redirect URIs:
    (kliknutím zkopíruješ) → Create.
  6. Zkopíruj sem Client ID a Client secret:

2 Připojit kanály

Klikni na tlačítko, vyber účet a konkrétní kanál, potvrď přístup (zaškrtni obě oprávnění). Opakuj pro každý kanál.

Google ukáže „Google hasn't verified this app“ – je to tvoje vlastní aplikace, klikni na Advanced → Go to … (unsafe).

3 Uložit do GitHubu (jedno vložení)

  2. Otevři GitHub → Settings → Secrets → New repository secret.
  3. Name: YT_DASHBOARD, Secret: vlož (Ctrl+V) → Add secret. Pokud už existuje, otevři ho a klikni Update.
  4. Spusť první stažení: Actions → YouTube dashboard → Run workflow. Dál už to běží samo každou hodinu.
  5. Otevři dashboard a zadej heslo.
Zobrazit / ručně upravit nastavení

Obsahuje přístupové klíče – nikam jinam než do GitHub Secrets ho nevkládej. Sem můžeš vložit dřív uložené nastavení a přidat k němu další kanál.
